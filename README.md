# Hazır kitaplar

Bu klasöre EPUB dosyalarını koy. Uygulama yalnızca dosyası burada bulunan kitapları gösterir.
Dosya adı `catalog.json` içindeki `file` alanıyla aynı olmalı. Kitap eklemek veya çıkarmak için `catalog.json`'u düzenle.

Project Gutenberg'den indir (resimsiz sürüm daha küçüktür) ve gösterilen adla kaydet:

- Pride and Prejudice: https://www.gutenberg.org/ebooks/1342.epub.noimages  ->  books/pg1342.epub
- Alice's Adventures in Wonderland: https://www.gutenberg.org/ebooks/11.epub.noimages  ->  books/pg11.epub
- The Adventures of Sherlock Holmes: https://www.gutenberg.org/ebooks/1661.epub.noimages  ->  books/pg1661.epub
- Frankenstein: https://www.gutenberg.org/ebooks/84.epub.noimages  ->  books/pg84.epub
- Dracula: https://www.gutenberg.org/ebooks/345.epub.noimages  ->  books/pg345.epub
- The Picture of Dorian Gray: https://www.gutenberg.org/ebooks/174.epub.noimages  ->  books/pg174.epub
